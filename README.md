# 탕방 (Tangbang) · 서울 목욕탕·사우나 지도

서울의 목욕탕·사우나·온천 **461곳**을 지도와 목록으로 보여 주고, **직접 확인한 요금**을 알려 주는 웹 서비스입니다.
처음 들어오면 노을 지는 목욕탕 장면이 나오고, 그 장면을 보는 사람이 "아, 목욕 갈까?" 하고 느끼게 하는 것이 디자인 목표입니다.

- 배포: https://tangbang.vercel.app (Vercel 프로젝트 `tangbang`, `main` 푸시 시 자동 배포)
- 저장소: `taeolee1310/10_23_map_test`
- 작업 일지: 노션 「공통작업 노트 > 04 프로젝트 > 탕방 프로젝트 일지」
- 이 문서는 대화 컨텍스트가 초기화돼도 작업을 이어갈 수 있게, 서비스 구조와 **그동안 정해진 결정·규칙**을 함께 적은 것입니다. 작업 규칙의 원본은 `CLAUDE.md`입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 화면 | React 18 + Vite 5 + TypeScript (`web/`) |
| 지도 | 카카오 JavaScript SDK (JS 키만 브라우저에 사용) |
| 데이터 정리 | 파이썬 + 판다스 (`onsen_merge.py`, `export_web_data.py`) |
| 데이터 수집 | ego-lite 브라우저로 직접 수집 (수집 스크립트는 만들지 않음) |
| 화면이 읽는 데이터 | `web/public/data/onsen.json` 한 파일 |
| 디자인 기준 | `web/src/styles/tangbang-colors.css` (컬러 시스템), Figma 인트로 v3 |

## 실행

```bash
cd web
npm install          # 처음 한 번 (설치 명령은 AI가 직접 돌리지 않고 제안만 함)
npm run dev          # http://localhost:5173  (127.0.0.1이 아니라 localhost로 열 것)
npm run build        # 타입 검사 + 빌드
```

`.env` (프로젝트 루트, 값은 사용자가 직접 넣고 절대 올리지 않음)

```
KAKAO_REST_API_KEY=   # 파이썬 전용. 화면에 넣지 않는다
KAKAO_JS_KEY=         # 지도용. vite.config.ts가 KAKAO_JS_ 접두어만 브라우저로 보낸다
```

카카오 콘솔 > JavaScript SDK 도메인에 `http://localhost:5173`, `https://tangbang.vercel.app`(와 쓰는 별칭)을 등록해야 지도가 뜹니다.
**`127.0.0.1`로 열면 지도가 안 뜹니다.**

## 폴더 구조

```
web/src/
├─ App.tsx                      인트로 → 메인 전환
├─ components/
│  ├─ BathhouseIntro/           첫 화면 (Figma 381:2 v3). scene.ts(장면 합성), waterfall.ts(물줄기 Canvas), bgm.ts(배경음)
│  ├─ GhostCursor/              마우스를 따라오는 연기 (React Bits, TS로 옮김. adaptive·excludeSelector·excludeNearSelector 옵션 추가)
│  ├─ ElasticSlider/            볼륨 슬라이더
│  ├─ GlideSelect/              정렬 드롭다운 (React Bits, 아이콘은 인라인 SVG)
│  ├─ KakaoMap/                 지도·핀·구별 묶음 마커·＋/－ 버튼
│  └─ OnsenLogo/                캐릭터 로고와 모션 (색은 토큰으로 칠함)
├─ screens/MainScreen/          머리말·목록·미리보기·상세
├─ lib/onsen.ts                 타입, 필터, 정렬, 시설 유형 묶음(kindGroup)
├─ styles/                      tangbang-colors.css(색), motion.css(움직임)
└─ assets/                      bathhouse/(Figma v3 에셋), map-pin/, onsen-logo/, banana-milk/, sound/

data/                           README.md 에 파일별 설명·출처·만드는 순서
├─ raw/ (올리지 않음)  collected/  curated/(사람이 확인)  merged/
```

데이터 만드는 순서: `python onsen_merge.py` → `data/merged/onsen_merged.csv` → `python export_web_data.py` → `web/public/data/onsen.json`.
(`onsen_official.py`는 병합 스크립트가 쓰는 함수가 있어서 남아 있음. 루트의 `place.py`, `geo.py`, `make_map.py`, `factcheck.py`, `map.html`은 수업 연습 파일로 React 화면과 무관하며 지울지는 미정.)

## 디자인 시스템

- 색은 `tangbang-colors.css`의 semantic·component 토큰만 씁니다(primitive는 화면 CSS에서 직접 쓰지 않음). 새 색 값을 직접 쓰지 않습니다. 구조·매핑·명암비 검증은 `docs/color-system.md`, 눈으로 보는 미리보기는 `docs/color-preview.html`(앱 밖 정적 파일)입니다.
- 주요 색(기준 8색): Warm Cream `#FDF6D0`(페이지 배경), Clean Ivory `#FFFDF5`(카드), Deep Cocoa `#342C25`(글자), Mocha Brown `#57483B`(보조 글자), Bath Teal `#527C77`(선택·시설), Warm Terracotta `#A64B31`(주요 버튼), Sand Beige `#E8D9AE`(머리말·구분), Apricot `#E7A36E`(장식). 인트로 그림·로고·캐릭터 색은 이미지 원본에서 뽑은 별도 값입니다.
- 지도 핀은 몸통(나무색) · 윤곽(갈색) · 욕조(크림) 세 겹 마스크, 선택하면 크림 몸통입니다.
- 로고 캐릭터도 토큰으로 칠합니다(윤곽선 `--color-outline`, 물 `--color-water`, 김 `--color-steam`).
- 담아두기 아이콘은 **바나나우유 SVG**이고 노란 색은 정체성이라 바꾸지 않습니다(카드, 미리보기, "담아둔 곳" 칩 모두 같은 아이콘).

## 인트로 구조 (가장 손이 많이 간 부분)

Figma 파일 `ojmQos2N59L7GQE76L26J6`의 `Bathhouse_Motion_v3 / 원본 질감 복원`(노드 `381:2`)이 기준입니다. **이 에셋만 씁니다. 임의로 합성하거나 새로 만든 에셋은 쓰지 않습니다.**
모든 레이어는 같은 1536×1024 무대에 놓고, 위치·크기는 `--u`(원본 1px이 화면에서 차지하는 길이)로 계산해서 화면 크기가 바뀌어도 어긋나지 않게 합니다.

레이어 순서 (뒤 → 앞):

1. **바탕 캔버스** (`scene.ts`): 수증기·물줄기가 없는 배경 + 하늘 원경 + 원본 물결 + 포말(물줄기 줄기만 지움)
2. **구름 덩어리**: 구름 마스크 A·B와 원본 질감이 한 요소 안에서 ±4px 움직임. 두 창이 같은 박자
3. **창틀·스카이라인 전경**(고정): 바탕에서 구름 모양만 비운 조각. 구름이 움직여도 이 뒤로 가려짐 → 창틀 쪽 검은 선이 생기지 않음
4. **해·수면 반사 밝기**: 원본에 겹쳐 밝기만 아주 조금 변화(Figma 값 8%, 6% 안쪽). 해는 구름과 따로 고정
5. **물줄기** (Canvas): 윤곽 고정, 안쪽 질감만 곡선을 따라 흐름, 가장자리 흔들림, 튀는 방울·포말·납작한 파문. 원본 물줄기를 곡선으로 펴 둔 `stream-strip.png`(원본에서 뽑은 질감 띠)를 씀
6. **수증기 3층**: 투명 PNG를 층 마스크로 오림. 뒤·중간·앞이 14·11·9초 주기로 20·30·40px 올라가며 옅어짐
7. **고스트 커서**: 화면 전체. CTA 버튼과 볼륨 영역(닿기 10% 전부터)에서는 나오지 않음. 느린 기기에서는 해상도를 자동으로 낮춤
8. 글자(CTA "목욕탕 찾아보기"), 볼륨 슬라이더(배경음 `public/audio/intro.wav`)

규칙: 창틀·스카이라인이 맨 앞, 구름·해는 그 뒤. 움직이는 레이어는 마스크로 쪼개지 말고 한 덩어리로 만든 뒤 앞 레이어가 가림. 모션 줄이기(`prefers-reduced-motion`)는 멈춘 한 컷으로 대체.

## 사용자가 정한 규칙 (대화에서 나온 것)

- **서울 전용**입니다. 전국 흔적(시·도 필터, 전국 문구)은 정리했습니다.
- **사용자 화면에 개발자용 설정·미리보기·디버그 UI를 넣지 않습니다.** ("서비스는 사용자 기준")
- 바나나우유 색 유지, 인트로 에셋은 Figma v3만 사용.
- 수집은 ego-lite로 하므로 수집 스크립트는 만들지 않음.
- 모션은 요청한 것만 넣습니다. 마우스 반응 효과는 고스트 커서만.
- 점검·검토를 요청하면 **수정하지 말고 제안만** 합니다. 수정을 요청하면 그때 고칩니다.
- 커밋·푸시는 사용자가 요청할 때만 합니다. 관련 없는 변경은 포함하지 않습니다.
- 삭제는 사용자가 말했을 때만, 깃에 없는 파일(`.gitignore` 원본)은 지우면 복구가 안 된다는 점을 먼저 알립니다.
- 답변은 한국어로 간결하게. 시간은 KST.

## 알려진 함정 (겪은 것)

- **`url()` 따옴표**: 빌드하면 작은 SVG는 `data:image/svg+xml,...'...'` 형태의 데이터 주소로 바뀝니다. 코드에서 `url(${src})`처럼 따옴표 없이 쓰면 운영(Vercel)에서만 CSS가 무효가 되어 **사운드 아이콘과 로고가 사라집니다**(개발 서버에서는 멀쩡해서 못 알아챔). 항상 `url("${src}")`로 씁니다. 운영 빌드는 `npm run build && npx vite preview`로 확인하세요.
- 지도는 `localhost:5173`으로만 뜹니다(카카오 도메인 등록 기준).
- `.gitignore`의 `data/raw/*`는 올라가지 않으므로 원본은 따로 보관해야 합니다.
- `web/public/audio/intro background.wav`는 `intro.wav`와 같은 음원의 중복 파일이라 커밋하지 않았습니다. 음원의 출처·저작권은 확인하지 못했습니다.

## 남은 일 (우선순위 순)

1. **운영 배포에서 사운드 아이콘·로고가 안 보이는 문제**: 원인은 위 `url()` 따옴표이고 수정은 작업 폴더에 반영했습니다. `main`에 푸시해야 Vercel에 반영됩니다(커밋·푸시 여부는 `git log`로 확인).
2. 화면 문구는 "온천" → "목욕탕"으로 통일함(시설 유형 버튼 "온천·숙박"과 데이터셋 이름 "행정안전부 온천이용업소 현황"은 그대로). 머리말의 중복 문구 정리와 코드 이름 `onsen`의 중립 이름 변경은 남음.
3. 지도 첫 화면에서 구별 묶음 마커가 겹침(시작 확대 단계·겹침 처리), 모바일 머리말이 첫 화면의 약 3분의 1을 차지함.
4. 인트로 글자 대비: 지금은 큰 글자 + 장면 26% 어둡게(평균 3.1~3.7:1, 밝은 반사 아래는 약 2.0:1). 단색 반투명 패널(최악 4.6:1 통과)로 돌아갈지 결정 필요. 측정은 화면 픽셀 근사라 DevTools로 재확인.
5. 재방문 사용자의 인트로 건너뛰기, 로딩 중 빈 화면 개선(저해상도 선로딩).
6. 선택한 장소 라벨, 지도 핀 상태 구분 보강.
7. 파이썬 연습 파일과 `--tb-character-blue`(이제 안 쓰임) 정리 여부 결정.

## 접근성 메모

대비는 `--ink`(갈색)가 흰 면 10:1, 크림 9.2:1, 주황 6.2:1이고 보조 글자(`--color-text-secondary`)는 흰 면 5.2:1입니다. 따뜻한 면(선택한 카드) 위에서는 `--muted-strong`을 씁니다. 토글 꺼짐 트랙은 나무색, 선택 카드는 나무색 2px 링과 막대, 스크롤 영역은 키보드 포커스 가능, 지도에는 ＋/－ 버튼(44px)이 있습니다.
검색창·칩의 테두리는 접근성 기준상 필수가 아니라서 넣지 않았습니다(글자·아이콘으로 식별됨).
