# 요금 제보 → 구글 시트 설정 순서

사용자가 제보하면 내 구글 시트의 `제보` 탭에 한 줄씩 쌓인다. 시트 설정과 Vercel 설정을 한 번만 하면 된다.

## 1. 시트 만들기
1. 구글 드라이브에서 새 구글 시트를 만든다. 이름은 `탕방 요금 제보`처럼 알아보기 쉽게 정한다.
2. 이 시트는 **나만 볼 수 있게** 둔다(공유하지 않는다). 제보 목록이 밖에 보이면 안 된다.

## 2. 받는 코드 붙이기
1. 시트 위쪽 메뉴 **확장 프로그램 > Apps Script**를 연다.
2. 기본으로 있는 코드를 지우고 `docs/apps-script-report.gs`의 내용을 전부 붙여 넣는다. 저장한다.
3. 왼쪽 **프로젝트 설정(톱니바퀴) > 스크립트 속성 > 속성 추가**에서 이름 `REPORT_SECRET`, 값은 **길고 아무도 모르는 문자열**(예: 비밀번호 생성기로 만든 32자)을 넣는다. 이 값은 대화나 깃에 적지 않는다.
4. 오른쪽 위 **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포를 누르고, 처음이면 권한 허용 안내가 뜬다(내 계정으로 허용).
5. 나온 **웹 앱 URL**을 복사해 둔다. (비밀 주소처럼 다룬다)

## 3. Vercel에 넣기
Vercel 프로젝트 `tangbang` > Settings > Environment Variables에 두 개를 Production(필요하면 Preview도)에 추가한다.
- `REPORT_SHEET_URL` = 2-5의 웹 앱 URL
- `REPORT_SHEET_SECRET` = 2-3에서 정한 비밀 값(같은 값)

추가한 뒤 **다시 배포(Redeploy)** 해야 적용된다.

## 4. 확인
배포된 사이트에서 업체 하나의 "요금 제보"를 보내 본다. 시트에 `제보` 탭이 생기고 한 줄이 들어오면 성공이다.
(처음 한 줄이 들어올 때 `제보` 탭과 제목 줄이 자동으로 만들어진다.)

## 검토하는 법
- 시트의 **상태** 칸을 `새 제보 → 확인함 → 반영 완료 / 반려`로 바꿔 가며 관리한다. `표시` 칸에 이상값·연락처 의심 등이 적혀 있다.
- **같은 값 횟수**가 클수록 여러 사람이 같은 값을 말한 것이다.
- 제보는 단서일 뿐이다. 근거(네이버 가격표·공식 홈페이지)를 확인한 값만 `data/curated/`에 넣고 `cargo run --release --bin export_web_data`로 화면 데이터를 다시 만든다.

## 주의
- Apps Script 웹 앱 URL이 새면 누구나 요청을 보낼 수 있지만, 비밀 값이 맞아야만 줄이 추가된다. 의심되면 `REPORT_SECRET`과 `REPORT_SHEET_SECRET`을 같이 바꾼다.
- 코드를 고친 뒤에는 **배포 > 배포 관리 > 수정(새 버전)** 으로 다시 배포해야 반영된다.
- 한 번에 많이 몰리면 일부가 실패할 수 있다(구글 한도). 제보 규모에서는 문제 없다.
