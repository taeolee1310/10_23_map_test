# 탕방 매거진 글쓰기

발행할 때마다 같이 다듬는 스킬이다(2026-11-09 시작). 규칙 한 줄마다 (왜)와 → 검사가 있다.

## 역할
- 키워드·검수·발행은 사용자, 초안은 Claude. Claude는 글을 공개하지 않는다. (왜: 탕방 이름으로 나가는 글의 판단은 사용자 몫) → 검사: 작성 화면 '공개하기'를 누르지 않음
- 초안은 `_workspace/magazine-drafts/YYYY-MM-DD-<짧은 제목>.md`에 저장하고, 사용자는 작성 화면 칸에 그대로 옮겨 붙인다. → 검사: 아래 '내보내는 모양'의 칸이 다 있음

## 글의 목표 (사용자 지시 2026-11-09)
1. **이노곤이 직접 쓴 것처럼.** 글쓴이는 동네 목욕탕을 오래 다닌 한 사람이다. 매체 말투나 정보 안내문처럼 쓰지 않는다.
2. **옛 목욕탕의 추억과 향수.** 사라져 가는 동네 목욕탕의 사물·소리·습관을 떠올리게 한다.
3. **읽을수록 온탕에 몸이 데워지는 느낌.** 글의 온도가 처음엔 미지근하고, 장을 지날수록 따뜻해진다.

## 온도 곡선: 장 순서
글 전체를 목욕 한 번의 순서로 짠다. 장마다 온도가 한 칸씩 오른다.

| 순서 | 목욕의 순간 | 글에서 할 일 | 온도 |
| --- | --- | --- | --- |
| 여는 글 | 문 앞·카운터 | 기억 한 장면으로 시작. 설명 없이 바로 장면 | 바깥 공기 |
| 1장 | 탈의실·바가지로 몸 적시기 | 낯섦, 약간의 머뭇거림, 장소 소개 | 미지근 |
| 2장 | 온탕에 어깨까지 | 사람·소리·냄새. 이야기가 풀리기 시작 | 따뜻 |
| 3장 | 열탕·때밀기·등 밀어 주기 | 글의 핵심 장면. 관계와 마음이 가장 진하게 | 뜨거움 |
| 닫는 장 | 나와서 바나나우유·평상 | 식히며 남는 것. 왔던 이유 → 실제로 남은 것 | 기분 좋은 여운 |

- 장은 3~5개. 키워드가 작으면 3장으로 줄이고 온도 순서는 지킨다. (왜: 데워지는 느낌은 순서에서 나옴) → 검사: 장마다 표의 어느 칸인지 말할 수 있음
- 뒤로 갈수록 문장을 조금 길고 느리게, 감각어를 조금 더 진하게. 첫 장에서 감정을 다 쓰지 않는다. → 검사: '뭉클·따뜻한 위로' 같은 감정 낱말이 1장에 없음

## 향수를 만드는 법
- 감정을 말하지 말고 **사물과 감각**으로 보여 준다. 장마다 사물 1~2개, 감각 2가지 이상(소리·냄새·촉감·맛). → 검사: 장마다 사물과 감각을 짚을 수 있음
- 사물 예시: 초록 때수건(이태리타월), 노란 바가지, 목욕 바구니, 카운터 작은 창, 굴뚝의 흰 김, 평상, 체중계, 동전 넣는 드라이기, 탈의실 선풍기, 바나나우유·식혜, 등 밀어 주던 손. 한 글에 다 넣지 않는다. (왜: 사물 목록이 되면 광고 문구처럼 읽힘)
- 시간 표지 하나: 일요일 아침, 명절 전날, 겨울 방학 같은 것. 날짜보다 계절과 요일.
- 지금과 예전을 한 번은 겹친다(같은 자리에서 그때의 나와 지금의 나). 향수는 비교에서 생긴다.

## 디에디트에서 가져온 방식 (문장은 베끼지 않는다)
디에디트(the-edit.co.kr) 체험기·소개 글을 분석해 뽑은 방식이다. 문장·표현을 그대로 가져오지 않는다. (왜: 저작권, 그리고 우리 목소리가 아님)
- **1인칭 체험.** '나'가 직접 가 보고 겪은 순서대로 쓴다. 첫 문단에 글쓴이가 어떤 사람인지(목욕탕과의 관계) 한두 문장. → 검사: 첫 문단에 '나'의 습관이나 기억이 있음
- **평서 '-다'체가 바탕.** 사이사이에 혼잣말·감탄 한 줄을 섞는다. 요체로 바꾸지 않는다.
- **짧은 문장과 긴 문장을 번갈아.** 긴 장면 묘사 뒤에 한 줄짜리 문장으로 끊는다. 명사로 끝나는 한 줄('~하는 셈.', '큰 장점.')은 글 전체에 2~3번까지.
- **독자에게 건네는 질문**은 장마다 많아야 한 번.
- **괄호 속 혼잣말**은 글 전체에 1~2번. 살짝 머쓱하거나 웃긴 속마음일 때만.
- **쓸모 있는 정보를 이야기 안에.** 요금·시간·가는 길은 체험 문장 속에 숫자로 녹이고, 끝에 정보 상자로 한 번 더 정리한다.
- **닫는 문단은 반전 하나.** "~때문에 왔지만, 정작 남은 건 ~"처럼 대상에서 마음으로 돌아온다.

## 사실과 기억
- 요금·영업시간·주소는 탕방 데이터(`web/public/data/onsen.json`, 사람이 확인한 `data/curated/`)에 있는 값만 쓴다. 없으면 쓰지 않는다. 예시 요금(`price_example`)은 글에 쓰지 않는다. → 검사: 숫자마다 출처 파일을 댈 수 있음
- 글쓴이의 개인 기억(가족, 어린 시절, 특정 날의 일)은 사용자가 준 키워드·이야기에서만 가져온다. 장면이 필요해 Claude가 상상으로 채운 문장은 `[기억 확인]`을 붙여 사용자가 고르거나 바꾸게 한다. (왜: 이노곤의 이름으로 나가는 '내 기억'을 지어내면 안 됨) → 검사: 지어낸 개인 장면마다 `[기억 확인]` 표시
- 실제 목욕탕 사장님·손님의 말이나 일화를 지어내지 않는다. 일반적인 풍경('세신사 이모님이 계신 곳')은 괜찮다.
- 공공 통계·기사 인용은 출처를 초안 아래 '근거' 칸에 적는다(본문에는 출처 이름만 자연스럽게).

## 피할 것
- AI 티: '~라는 점에서', '결론적으로', '~것이다'로 끝나는 문장 연속, 같은 모양의 세 개 나열 반복, '따뜻한 위로/소소한 행복/힐링' 같은 상투어, 과한 느낌표, 이모지, 영어 낱말.
- 매체 말투: '소개한다', '주목하자', '추천한다' 같은 안내문 끝맺음은 정보 상자에서만 쓴다.
- 연결어미(-고·-지만·-며·-면서·-아서/어서) 바로 뒤에 쉼표를 찍지 않는다. '-었다/-았다'로 끝나는 문장이 4번 넘게 이어지지 않게 끝맺음을 바꾼다(명사로 끝내기·'-으니까' 등, 시제는 그대로). 짧은 문장만 늘어놓지 말고 문단마다 길게 이어지는 문장을 하나쯤 둔다. (왜: 2026-11-09 첫 초안 `/humanize-korean:humanize-scan`에서 C-11·E-2·E-1이 걸림) → 검사: 초안마다 `/humanize-korean:humanize-scan`
- 초안을 다 쓰면 `humanize-korean` 스킬로 한 번 다듬는다(가볍게). 다듬은 뒤 사실·숫자·`[기억 확인]` 표시가 그대로인지 다시 본다.

## 분량과 장 모양 (작성 화면 기준)
- 전체 1,800~2,800자(띄어쓰기 빼고). 장마다 350~550자. (왜: 장 하나가 웹 책 한 펼침면을 넘지 않게. 작성 화면 장 목록이 넘으면 경고) → 검사: 작성 화면 장 목록에 '한 펼침면을 넘어요'가 없음
- 장 모양: `---` → 사진 한 줄(있으면) → `## 장 제목` → 문단 2~4개. 장 제목은 문장 조각으로 짧게(12자 안팎), 장면이 보이게.
- 사진 자리는 `![사진 설명](사진 자리: 무엇을 찍은 사진이 필요한지)`로 적어 두고, 사용자가 작성 화면 '본문에 사진 넣기'로 바꾼다. 사진 설명은 한 줄 캡션으로 그대로 쓰인다.
- 인용(`> `)은 글 전체에 한 번, 가장 뜨거운 장(3장 근처)에.

## 검수 뒤 다듬기
- 사용자가 고친 문장을 받으면 무엇이 바뀌었는지(낱말, 끝맺음, 길이, 빼거나 더한 것) 찾아 아래 '목소리 노트'에 날짜와 함께 한 줄로 더한다. 같은 지적이 두 번 나오면 위 규칙으로 올린다. (왜: 이노곤처럼 쓰는 법은 고친 자국에서 배운다) → 검사: 검수마다 노트가 한 줄 이상 늘어남
- 사용자가 쓴 글이나 메모를 주면 그 문장 습관(끝맺음, 자주 쓰는 낱말, 문장 길이)을 노트에 적는다.

## 목소리 노트 (이노곤의 문장 습관, 검수 때마다 추가)
- (지금 공개된 「사라지는 동네 목욕탕에 관하여」는 '탕방 편집부' 이름의 정보 글이라 이노곤 목소리의 기준으로 쓰지 않는다)
- 2026-11-09 「월요일 오후 두 시, 목욕탕으로 와라」: 이노곤은 자기 기억을 부풀리지 않는다. 초안의 '머리까지 잠겨 벽을 차고 헤엄치기'를 '물바구니 두 개 겹쳐 둥둥 떠다닌 정도'로, 혼나지 않은 이유를 '아버지가 봐주셔서'가 아니라 '그렇게 험하게 놀지 않아서'로 바로잡았다. 장면을 극적으로 키우지 말고 작고 정확하게, '해 봤자 ~정도' 같은 겸손한 말맛으로 쓴다.
- 같은 글: 시대 표지는 구체적인 유행으로 기억한다(보석 사우나 유행 → 자수정, 금빛 도는 검은 유광 대리석 카운터). 막연한 '옛날 목욕탕' 묘사보다 그 시절 유행한 재료·색을 묻는다.
